# 几乎线性的单源最短路（中文译稿 + C 实现）

论文：**Linear Single-Source Shortest Path, Almost**
Iman Gholami, MohammadTaghi Hajiaghayi（University of Maryland）
[arXiv:2611.34911v1](https://arxiv.org/abs/2611.34911)，2026-11-25。

论文给出比较–加法模型下无向图单源最短路的算法：对任意 $n$ 个顶点、$m$ 条边、边长为
任意非负实数的输入，期望运行时间 $O(m + n\log\log\log n)$，几乎必然终止，每次终止都
返回精确距离与一棵最短路树；时间界与边长比值无关。

本仓库包含两件东西：

1. `typst/` —— 论文全文的中文译稿（Typst 排版），成品见 [`typst/paper-zh.pdf`](typst/paper-zh.pdf)。
2. `c/` —— 论文算法的 C 语言实现，并与 Dijkstra 对拍验证。

## C 实现

```bash
cd c
make
./sssp --n 400 --m 1200 --verify           # 常数规模基例（扫描版 Dijkstra）
./sssp --n 400 --m 1200 --sep 2 --verify   # 走层级路径（缩放的分隔规模）
./sssp --bench
```

实现与论文的对应关系、验证方法与已知偏差都写在 [`c/README.md`](c/README.md)，摘要：

| 论文 | 实现 |
|---|---|
| §2 比较–加法模型 | `len.h`：长度是不透明寄存器，只允许复制/相加/比较/加倍，并统计运算量 |
| §3 原语 | 扫描版/堆版 Dijkstra、算法 1 的三趟有界生长 MST、并查集、倍增 LCA 与瓶颈查询 |
| §5.1 归属分解 | 枢纽集标记、斯坦纳分支顶点、走廊割、归属单元、$r_v/R_v$、$T_A$ 与 $\sigma$ |
| §6 路由证书 | 算法 2、3：抽样、合并森林、权重带、收缩商图、随机中心分解、划分树 |
| §7 归属坐标 $J$ | 辅助图 Dijkstra（与论文同一个 $J$） |
| §8.1 状态图 | $K=16$ 双壳窗口、近/远转移、相位切换、宏观重置、归属树特殊状态 |
| 阈值分量与层级 | 瓶颈 Dijkstra 求 $I_0/O_0/I_*/O_*$ 与 $\theta$；按倍增网格类同时合并 |

验证：`--verify` 与 Dijkstra 逐顶点对拍，`n=20\ldots100` 的随机图与路径图 12/12 一致，
`n=800` 亦一致；`hier_validate` 检查层级区间不变量。

**已知偏差**（详见 `c/README.md`）：算法 7/8 的槽扫描已实现（`--slot`），但部分实例上
仍会漏发或发出偏大值，因此默认在构造出的状态图上做精确搜索——这一步验证的是 §8.1
构造的忠实性（引理 8.1/5.5：状态图必须以原长度实现每条测地线），而不是求值过程本身。
§7.3 的宽度日历与 §5.4 的原子替换未实现。
